NE 361 — Computational Design in Nuclear Engineering

Concept 1: Interpreted vs. Compiled Languages

Answer:

  • Compiled: Source code is translated entirely into machine code before execution by a compiler. The resulting executable runs directly on hardware — fast at runtime, but requires a compile step. Examples: C, C++, Fortran (used in many nuclear codes like MCNP).
  • Interpreted: Source code is read and executed line-by-line by an interpreter at runtime — no separate compile step, easier to debug interactively, but generally slower. Examples: Python, MATLAB, Perl.
